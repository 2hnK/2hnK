## 01. About

백엔드와 생성형 AI를 연결해 **실제로 사용할 수 있는 서비스**를 만드는 개발자 김지훈입니다.<br />
Java·Spring 기반 서버 개발을 중심으로, Spring AI와 LangChain을 활용한 AI 응용 서비스를 만들고 있습니다.
